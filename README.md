<p>Создание проекта.</p>
<p>Базовая настройка логирования. Реализация базы Агента для сбора параметров. Он имеет следующую структуру:</p>
<p>collectors/</p>
<p>├── __init__.py          # Экспорт всех коллекторов</p>
<p>├── base.py              # Базовый класс и утилиты</p>
<p>├── cpu.py               # CPU, частоты, температура</p>
<p>├── memory.py            # RAM, Swap</p>
<p>├── disk.py              # Диски, I/O</p>
<p>├── network.py           # Сеть, интерфейсы, соединения </p>
<p>├── system.py            # Информация о системе </p>
<p>└── devices.py           # Подключённые устройства (USB, принтеры). </p>
</p>Реализация упаковки всей информации в словарь для будущей отправки.</p>
</p>Реализация тестового функционала main.</p>
