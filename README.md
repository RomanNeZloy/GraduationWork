Создание проекта.
Базовая настройка логирования. 
Реализация базы Агента для сбора параметров. Он имеет следующую структуру:
collectors/
├── __init__.py          # Экспорт всех коллекторов
├── base.py              # Базовый класс и утилиты
├── cpu.py               # CPU, частоты, температура
├── memory.py            # RAM, Swap
├── disk.py              # Диски, I/O
├── network.py           # Сеть, интерфейсы, соединения
├── system.py            # Информация о системе
└── devices.py           # Подключённые устройства (USB, принтеры).
Реализация упаковки всей информации в словарь для будущей отправки.
Реализация тестового функционала main.
